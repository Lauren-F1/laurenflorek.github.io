# CLAUDE.md, standing rules for laurenonlife.com

Read this file at the start of every session before touching anything.

## Who this site belongs to

Lauren Florek: executive coach, speaker, and author. This site (laurenonlife.com) is her personal brand, aimed at writing, speaking, and women leaders. Her coaching business lives separately at newmindsetfoundation.com, which is built on a website builder and is not part of this repository.

Lauren is not a developer. Explain everything in plain English, assume no coding knowledge, and give numbered steps she can follow exactly. When she needs to do something outside the chat (rename a file, click a button, change a setting), say exactly where that button is. If she sounds confused, slow down instead of adding more detail.

## How the site works

- Plain HTML and CSS, no frameworks. Keep it that way.
- Repository: laurenflorek.github.io under GitHub username Lauren-F1.
- Published through GitHub Pages. The custom domain laurenonlife.com is registered but not yet connected.
- Files: index.html (home), book.html, speaker.html, css/styles.css, and an /images/ folder.
- Lauren publishes changes with GitHub Desktop: commit to main, then push origin.

## Writing rules (absolute)

1. Never use em dashes. Not in copy, not in messages, not in code comments. Use commas, colons, periods, or parentheses instead.
2. Everything must read as human-made, never AI-generated. Banned words: unlock, elevate, empower, journey, transformative, seamless, dive in, in today's world.
3. No emoji, anywhere.
4. Voice: warm, direct, honest, a little wry. Like a person, not a landing page.
5. Avoid compressed parallel headline constructions (patterns like 'Four talks, one body of work' or 'Less noise, more truth'). They read as AI-written. Plain or working headlines instead.
6. Contractions are the house style, but never contract a name with 's where it reads as possessive; write Lauren is, not Lauren's, in those spots.

## Design rules

- Editorial and restrained, like a small independent publisher. Not a SaaS landing page.
- No three-column card grids with circular icons on top.
- No gradients, no glassmorphism, no glowing effects.

## Brand system (shared with newmindsetfoundation.com)

Colors:

- Ink #292826: text and dark sections
- Soft Stone #B8AB9D: secondary text, rules, borders
- Warm Paper #F4EFE7: main background
- Porcelain #FCFAF7: alternate background
- Electric Citron #E5F21A: signature accent, tiny amounts only. Never a background, never a button fill, never behind text.
- Soft Blush #FFF1ED: softer accent for book and personal-brand contexts

Type:

- Headlines: Playfair Display from Google Fonts (standing in for Prism Display, the true brand font, which is not available free)
- Body: Montserrat

Brand attributes: elevated, human, transformative, trusted, modern. These describe how the site should feel. Two of these words (elevate, transformative) are on the banned list above, so never let them appear in visible copy.
